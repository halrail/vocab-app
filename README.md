# vocab-app

## 概要
Web上で動作する、単語帳アプリです。ログイン機能を備えており、自分だけの進度で単語勉強をするめることができます。

## 使い方
開発者（aqs_port）によって登録された単語による勉強は新規登録とログインによって誰でも簡単に行うことができます。
各自で単語を変更したい場合には、Supabaseとの連携によるSQL tableの作成が必要です。

## 特徴
- 🚀 Supabaseと連携したログイン機能
- 🛠️ スタイリッシュなデザイン
- 📱 「今日の単語」機能により少しづつ覚えることができる

## 導入する場合の必要環境
- Supabase
